# 🛒 FreshBasket

A full-stack web application for managing a vegetable and fruit shop, including order handling, billing, inventory tracking, and customer management.

---

## 🚀 Features

### 👨‍💼 Admin Panel
- Dashboard with business insights  
- Product & category management  
- Order management system  
- Customer management  
- Stock tracking & waste tracking  
- Billing system with invoice generation  

### 👤 User Panel
- User authentication (Login / Signup)  
- Browse products by category  
- Add to cart & checkout  
- Order history & tracking  
- Profile management  

### 💡 Additional Features
- WhatsApp integration for notifications  
- Invoice generation system  
- Clean UI for both admin and users  

---

## 🛠 Tech Stack

**Frontend:**
- React.js  
- HTML, CSS  

**Backend:**
- Node.js  
- Express.js  

**Database:**
- MySQL  

**Integrations:**
- WhatsApp API  
- Razorpay
